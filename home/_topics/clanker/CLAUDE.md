# Global preferences

- I primarily work in Rust and TypeScript, on Linux (usually NixOS).
- Use Bash (`/usr/bin/env bash`) for scripts and general commands, not my customized ZSH.
- Never sign commits: always pass `--no-gpg-sign` to `git commit`.
- Always pass `--no-ext-diff` to git commands that produce diffs.
- Python is not installed unless the project needs it. `jq`, `rg` (ripgrep) and `fd` are always available.
